# CGM Lab Assignment 1 - Basic Shapes

## Objective
To understand and implement basic graphics primitives using C++ and the `graphics.h` library.

## Shapes Drawn
The program draws the following basic graphics primitives in a 2x2 grid layout:

1. **Straight Line** - using `line()`
2. **Circle** - using `circle()`
3. **Rectangle** - using `rectangle()`
4. **Triangle** - using three `line()` segments

## Technologies Used
- C / C++
- graphics.h (WinBGIm)
- VS Code
- MSYS2 UCRT64 (GCC / G++)
